# NEXORA AI 🤖

NEXORA AI is a multi-functional AI assistant built with **React, Python, and FastAPI**.

### Features
- AI Chat & Conversation History
- Web Search & Website Reader
- PDF and TXT Document Upload
- AI Image Analysis
- AI Image Generation
- Voice Input & Speech Responses
- Dark & Light Mode

### Technologies
React · JavaScript · Vite · Python · FastAPI · Uvicorn · Hugging Face · Gradio Client
